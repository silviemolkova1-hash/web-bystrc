# Bystrc Obora – web developerského projektu

Statický web (náhled) pro projekt Bystrc Obora – dva bytové domy v Brně-Bystrci.

- `index.html` – hlavní stránka
- `ochrana-osobnich-udaju.html` – zásady ochrany osobních údajů
- `cookies.html` – zásady cookies
- `img/` – vizualizace a fotky lokality

Nasazení: Cloudflare Pages (stačí napojit tento repozitář, bez build kroku).

Pozn.: Údaje v hranatých závorkách (počty bytů, ceny, kontakty, IČO…) jsou zástupné a doplní se od developera.
